## Описание программы

Инструкция установки программного обеспечения Git📟

### Необходимые условия

Что нужно для установки программного обеспечения и как его установить:
 1. Компьютер
 1. Интернет
 1. Прямые руки

> [!NOTE]
> Для установки официального софта вам придётся перейти на сайт https://git-scm.com/ .
```python
import subprocess
try:
  subprocess.run(["git","--version"], check=true)
  print("Гит установлен на компьютере🎱")
  except FileNotFoundError:
print("Гит не установлен. Скачайте с сайта указанного в репозитории")
``` 
> [!WARNING]
> Прочитайте инструкцию при установке.

### Как установить:
